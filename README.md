# 🦀 EcoKids - Experiencias Creativas

Sitio web para talleres infantiles creativos en Concón, V Región.

🌐 **[Ver sitio en vivo](https://ecokids-two.vercel.app)**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/hernanazocar/ecokids)

## ✨ Características

- 🎨 Diseño colorido y dinámico con animaciones CSS
- 🦀 Mascota del cangrejo con animaciones interactivas
- 🌊 Burbujas y olas animadas de fondo
- 📱 Completamente responsive
- ⚡ Next.js 16 con Turbopack
- 🎯 SEO optimizado para búsquedas locales

## 🚀 Inicio Rápido

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🎯 Servicios

- **Talleres Creativos**: Arte, manualidades y diversión
- **Cumpleaños**: Fiestas inolvidables llenas de color
- **Aventuras Marinas**: Experiencias bajo el mar ($7.000)

## 📍 Ubicación

Concón - V Región, Chile
