# Ecokids - Experiencias Creativas

## Descripción del Proyecto
Ecokids es un proyecto de talleres infantiles enfocado en experiencias creativas y educativas. Ofrece talleres, cumpleaños y actividades para niños en la V Región (Concón).

**Tagline:** "Un ratito sin pantallas, un mundo de posibilidades"

## Información del Negocio
- **Ubicación:** Concón - V Región
- **Servicios:**
  - Talleres creativos
  - Cumpleaños
  - Actividades especiales
  - Eventos especiales bajo el mar ($7.000)

## Branding
- **Mascota:** Cangrejo naranja (elemento principal del branding)
- **Colores:** Naranja vibrante, azul mar, colores pasteles
- **Estilo:** Amigable, infantil, creativo, natural/ecológico

## Stack Tecnológico
- **Framework:** Next.js 16 (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Turbopack** (dev server optimizado)

## Estructura del Proyecto
```
ecokids/
├── app/
│   ├── page.tsx           # Landing page principal
│   ├── talleres/          # Página de talleres

│   ├── galeria/           # Galería de fotos
│   └── contacto/          # Formulario de contacto

```
