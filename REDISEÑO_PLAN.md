# Plan de Rediseño - EcoKids Landing

## Patrón de Diseño Base (según "Quiénes Somos")

### Características del patrón:
1. **Fondos coloridos con degradados suaves** (orange→pink→purple)
2. **Cards blancas con hover effects** (hover:shadow-2xl hover:-translate-y-1)
3. **Iconos SVG en contenedores con gradientes** (no emojis)
4. **Bordes de 2px con colores temáticos**
5. **Headers con badges redondeados y gradientes**
6. **Tipografía clara**: text-xl para títulos de card, text-sm para descripciones
7. **Grid responsive**: md:grid-cols-2 lg:grid-cols-3
8. **Espaciado consistente**: p-6 para cards, gap-6 para grids

## Secciones a Rediseñar:

### 1. ✅ Quiénes Somos (PATRÓN BASE)
- 3 cards principales con iconos grandes
- Grid de 6 valores con iconos
- Colores: orange, blue, purple, green, yellow, teal

### 2. 🔄 Servicios
- Mantener card grande de Talleres Creativos

- Banner CTA al final

### 3. 🔄 Cómo Funciona

- Colores: blue, purple, green

### 4. 🔄 Testimonios
